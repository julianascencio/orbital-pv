# ALISIO-1 first observations

**Image credit © IACTEC-Espacio, Instituto de Astrofísica de Canarias (IAC).**

`la_palma.png` and `el_hierro.png` are the original false-colour DRAGO-2
composites from the [IAC media collection](https://cloud.iac.es/index.php/s/RS9pKNp272N5LEL).
The folder `Primeras imágenes ALISIO-1 (Feb. 2024)/Imágenes` contains the
originals and the provider's caption file, `pie de foto.txt`. The IAC
[published the observations on 16 February 2024](https://www.iac.es/en/outreach/news/first-observations-canary-islands-satellite-alisio-1-space).
The publication date does not establish the acquisition date for either island.
