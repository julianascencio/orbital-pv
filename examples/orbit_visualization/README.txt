Orbit Visualization
===================

These examples visualize representative Earth-orbit geometries around a 3D
planet and as Earth-fixed ground tracks.

They are intentionally deterministic and offline so the documentation build
does not depend on live orbital-element services.

The examples are educational geometry visualizations. Production mission
analysis should use the OrbitalPV propagation adapters with a traceable OMM,
TLE, ephemeris, or SPICE source.
