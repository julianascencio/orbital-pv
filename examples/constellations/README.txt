Constellation solar generation
==============================

These examples show how to use the public ``orbitalpv`` API for
constellation-scale orbital and photovoltaic simulations.

The Starlink example uses the FCC-authorized first-generation 550 km shell
geometry: 1,584 satellites at 53° inclination in 72 planes with 22
satellites per plane.

Power-system assumptions in the example are intentionally illustrative and
are not presented as SpaceX hardware specifications.
